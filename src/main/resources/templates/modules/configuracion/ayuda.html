1. Configuración de Empresa

¿Qué es?

La configuración de empresa almacena los datos principales de tu negocio que aparecerán en facturas, reportes y comunicaciones oficiales.

Campos Requeridos:

  • Razón Social: Nombre legal completo de la empresa (mínimo 3 caracteres)
  • RUC/NIT: Número de identificación tributaria (11 caracteres para Perú)
  • Dirección: Dirección fiscal de la empresa
  • Teléfono: Número de contacto principal
  • Email: Correo electrónico corporativo

Campos Opcionales:

  • Nombre Comercial: Nombre con el que se conoce tu negocio
  • Logo: URL de la imagen del logo (aparecerá en facturas)
  • Sitio Web: Dirección de tu página web
  • Representante Legal: Nombre del gerente o propietario
  • Régimen Tributario: RUS, RER, Régimen General, etc.
Importante: Esta información aparecerá en todas las facturas generadas. Asegúrate de que los datos sean correctos antes de emitir documentos.

2. Configuración de Facturación

¿Qué es?

Controla cómo se generan y formatean las facturas en tu sistema, incluyendo numeración, impuestos y moneda.

Numeración de Facturas:

Campo Descripción Ejemplo
Serie Código de serie de la factura F001, FV01, B001
Número Inicial Desde qué número empezar 1, 1000
Prefijo Texto antes del número (opcional) FAC-, INV-
Formato Estructura del número completo {serie}-{numero}

Resultado de Numeración:

Serie: F001
Número: 00025
Formato: {serie}-{numero}
Resultado: F001-00025

Configuración de Impuestos (IGV/IVA):

  • Porcentaje IGV: Tasa de impuesto (18% para Perú, 19% para Colombia)
  • Incluir IGV en precio:
    • ✅ Activado: El precio del producto YA incluye el IGV
    • ❌ Desactivado: El IGV se suma al precio base
  • Decimales: Cantidad de decimales en montos (normalmente 2)

Configuración de Moneda:

Moneda Código ISO Símbolo
Sol Peruano PEN S/
Dólar Americano USD $
Euro EUR €
Precaución: No modifiques la numeración o serie si ya tienes facturas emitidas. Esto podría causar duplicados o problemas legales.

Términos y Condiciones:

Puedes agregar texto que aparecerá al final de cada factura. Por ejemplo:

- El pago se debe realizar dentro de los 30 días.
- No se aceptan devoluciones después de 7 días.
- Banco: BCP - Cuenta: 193-1234567890
- Gracias por su compra.

3. Configuración de Email (SMTP)

¿Qué es?

Configura el servidor de correo para enviar facturas, notificaciones y reportes automáticamente a tus clientes.

Proveedores SMTP Comunes:

Gmail
Servidor: smtp.gmail.com
Puerto: 587 (TLS) o 465 (SSL)
Seguridad: TLS o SSL
Nota: Debes activar "Contraseñas de aplicación" en tu cuenta de Google.
Outlook
Servidor: smtp.office365.com
Puerto: 587
Seguridad: TLS

Campos de Configuración:

  • Servidor SMTP: Dirección del servidor de correo (ej: smtp.gmail.com)
  • Puerto: Normalmente 587 (TLS) o 465 (SSL)
  • Usuario: Tu dirección de correo completa
  • Contraseña: Contraseña o contraseña de aplicación
  • Email Remitente: Email que aparecerá como remitente
  • Nombre Remitente: Nombre que aparecerá (ej: "Mi Empresa SAC")
Seguridad: La contraseña se almacena encriptada. Nunca se mostrará en texto plano por seguridad.

Probar Configuración:

Usa el botón "Enviar Email de Prueba" para verificar que tu configuración funciona correctamente. El sistema enviará un correo de prueba a la dirección configurada.

Email de Prueba:
Para: tu-email@ejemplo.com
Asunto: Prueba de Configuración SMTP
Contenido: Mensaje de prueba con fecha y hora

4. Parámetros del Sistema

¿Qué son?

Los parámetros del sistema son valores configurables que controlan el comportamiento de diferentes módulos sin necesidad de programación.

Categorías de Parámetros:

Parámetro Descripción Valor Ejemplo
APP_NOMBRE Nombre de la aplicación ERP Orders Manager
APP_VERSION Versión actual del sistema 1.0.0
TIEMPO_SESION Tiempo de inactividad antes de cerrar sesión (minutos) 30
PAGINA_REGISTROS Cantidad de registros por página en listados 10

Parámetro Descripción Valor Ejemplo
WHATSAPP_ACTIVO Habilitar o deshabilitar módulo de WhatsApp true / false
WHATSAPP_RESPUESTA_AUTO Activar respuestas automáticas true / false
WHATSAPP_MENSAJE_BIENVENIDA Mensaje automático de bienvenida ¡Hola! Bienvenido a [empresa]
WHATSAPP_HORARIO_ACTIVO_INICIO Hora de inicio de atención 09:00
WHATSAPP_HORARIO_ACTIVO_FIN Hora de fin de atención 18:00

Parámetro Descripción Valor Ejemplo
FACTURA_DIAS_VENCIMIENTO Días hasta el vencimiento de una factura 30
FACTURA_ALERTA_VENCIMIENTO Días de anticipación para alertas 5
FACTURA_INCLUIR_LOGO Incluir logo de empresa en PDFs true / false
FACTURA_DESCUENTO_MAXIMO Porcentaje máximo de descuento permitido 20.00

Parámetro Descripción Valor Ejemplo
NOTIF_EMAIL_ACTIVO Habilitar notificaciones por email true / false
NOTIF_WHATSAPP_ACTIVO Habilitar notificaciones por WhatsApp true / false
NOTIF_WEB_ACTIVO Habilitar notificaciones web en tiempo real true / false
NOTIF_DIAS_RETENER Días para retener notificaciones antes de eliminar 90
Tip: Puedes filtrar parámetros por categoría o buscar por clave para encontrar rápidamente lo que necesitas.

5. Preguntas Frecuentes (FAQ)

Respuesta: No se recomienda. Cambiar la numeración puede causar duplicados y problemas legales. Si necesitas una nueva serie, contacta con soporte.

Pasos:
  1. Activa la verificación en 2 pasos en tu cuenta de Google
  2. Ve a https://myaccount.google.com/apppasswords
  3. Selecciona "Correo" y "Otro (nombre personalizado)"
  4. Escribe "ERP Sistema" y genera la contraseña
  5. Copia la contraseña de 16 caracteres y úsala en la configuración

Soluciones:
  • Revisa la carpeta de spam/correo no deseado
  • Verifica que el servidor SMTP y puerto sean correctos
  • Confirma que la contraseña sea correcta (usa contraseña de aplicación)
  • Verifica que tu proveedor de email permita SMTP
  • Revisa los logs del sistema para más detalles del error

Respuesta: Actualmente el sistema soporta una moneda principal configurada en "Configuración de Facturación". Para manejar múltiples monedas, deberás cambiar la configuración según la transacción o contactar con soporte para módulos avanzados.

Respuesta: El sistema tiene valores por defecto para todos los parámetros. Si modificaste un parámetro y quieres restaurarlo:
  1. Ve a la sección "Parámetros del Sistema"
  2. Busca el parámetro que deseas restaurar
  3. Haz clic en "Editar"
  4. Consulta la documentación para el valor por defecto
  5. O contacta con soporte para que te ayude
