# Edición de perfil

Referencia visual para editar datos personales, contraseña y avatar.

## Archivo real
- `src/main/resources/templates/modules/seguridad/perfil/editar.html`

## Estado visual
- Vista propia con CSS inline.
- No usa el layout compartido `shared/layout.html`.

## Secciones clave
- Datos personales
- Cambio de contraseña
- Subida/eliminación de avatar
- Acciones de guardado y cancelación
