# Iconografía

Referencia de iconos usados en la UI.

## Librerías activas
- Font Awesome 6.4.0
- Bootstrap Icons 1.10.0

## Carga global
- `src/main/resources/templates/shared/layout.html`

## Convención rápida

### Navegación
- Dashboard: `fa-home`
- Volver: `fa-arrow-left`
- Configuración: `fa-cog`

### Módulos
- Clientes: `fa-users`
- Productos: `fa-box`
- Facturas: `fa-file-invoice-dollar`
- Reportes: `fa-chart-bar`
- WhatsApp: `fab fa-whatsapp`

### Acciones
- Crear: `fa-plus`
- Editar: `fa-edit`
- Eliminar: `fa-trash`
- Ver detalle: `fa-eye`

## Nota
- Mantener el mismo icono para la misma acción.
- Usar Bootstrap Icons solo cuando ya exista en la vista.
