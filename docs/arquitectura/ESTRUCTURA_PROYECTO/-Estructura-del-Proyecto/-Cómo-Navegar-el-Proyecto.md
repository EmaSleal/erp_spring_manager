## 🔍 Cómo Navegar el Proyecto

### Buscar Entidades
```
📁 models/*.java
```

### Buscar DTOs
```
📁 models/dto/*DTO.java
```

### Buscar Records
```
📁 models/records/*Record.java
```

### Buscar Lógica de Negocio
```
📁 services/*Service.java
```

### Buscar Queries SQL
```
📁 repositories/*Repository.java
```

### Buscar Vistas
```
📁 templates/**/*.html
```

### Buscar Estilos
```
📁 static/css/*.css
```

### Buscar Interacciones JS
```
📁 static/js/*.js
```
