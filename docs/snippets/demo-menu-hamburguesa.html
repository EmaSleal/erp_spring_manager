Menú Hamburguesa Responsive

Este es un demo del sistema de navegación responsive implementado en el proyecto. El sidebar se adapta automáticamente según el tamaño de la pantalla.

Modo Desktop (> 768px)

En pantallas grandes, el sidebar es visible permanentemente en el lado izquierdo. Proporciona acceso rápido a todos los módulos del sistema.

✓ Sidebar visible ✓ Sin botón hamburguesa ✓ Navegación directa

Modo Móvil (≤ 767px)

En dispositivos móviles, el sidebar está oculto por defecto para maximizar el espacio de contenido. Aparece un botón flotante en la esquina inferior derecha.

✓ Botón hamburguesa flotante ✓ Sidebar deslizable ✓ Overlay de cierre ✓ Auto-cierre al navegar

Características

✨ Transiciones suaves: Animaciones fluidas al abrir/cerrar

🎨 Diseño moderno: Gradientes y sombras elevadas

♿ Accesible: Compatible con lectores de pantalla

📱 Touch-friendly: Botones grandes para móvil

🚀 Rendimiento: CSS puro, sin frameworks pesados

Cómo Probar

Opción 1 - DevTools:

1. Presiona F12 para abrir las herramientas de desarrollo

2. Presiona Ctrl+Shift+M para activar el modo responsive

3. Selecciona un dispositivo móvil de la lista

4. Observa el botón hamburguesa en la esquina inferior derecha


Opción 2 - Redimensionar:

1. Reduce el ancho de la ventana del navegador

2. Cuando sea menor a 768px, aparecerá el botón hamburguesa

3. Click en el botón para abrir/cerrar el menú
