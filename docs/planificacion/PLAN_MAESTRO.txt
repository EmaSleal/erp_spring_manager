------------------

FASE 3: MODELO DE DATOS - NUEVAS ENTIDADES
================================================================================

3.1 ENTIDAD: Pedido
-------------------
@Entity
@Table(name = "pedido")
Campos:
- idPedido (PK)
- cliente (FK)
- fecha
- fechaEntrega
- estado (ENUM: PENDIENTE, EN_PROCESO, ENTREGADO, CANCELADO)
- total
- observaciones
- lineasPedido (OneToMany)
- createDate, updateDate, createBy, updateBy

3.2 ENTIDAD: Pago
-----------------
@Entity
@Table(name = "pago")
Campos:
- idPago (PK)
- factura (FK)
- monto
- fechaPago
- metodoPago (ENUM: EFECTIVO, TRANSFERENCIA, TARJETA, OTRO)
- referencia
- observaciones
- createDate, updateDate, createBy, updateBy

3.3 ENTIDAD: Stock (Mejorar Inventario)
----------------------------------------
@Entity
@Table(name = "stock")
Campos:
- idStock (PK)
- producto (FK)
- almacen (FK - futuro)
- cantidad
- stockMinimo
- stockMaximo
- fechaUltimaActualizacion
- createDate, updateDate, createBy, updateBy

3.4 ENTIDAD: MovimientoInventario
----------------------------------
@Entity
@Table(name = "movimiento_inventario")
Campos:
- idMovimiento (PK)
- producto (FK)
- tipoMovimiento (ENUM: ENTRADA, SALIDA, AJUSTE)
- cantidad
- motivo
- documento (referencia a factura, pedido, etc.)
- createDate, createBy

FASE 5: FLUJO DE NAVEGACIÓN
================================================================================

5.1 FLUJO POST-LOGIN
--------------------
1. Usuario ingresa credenciales en /auth/login
2. AuthController valida
3. Si éxito -> Redirect a /dashboard
4. Dashboard carga:
   - Tarjetas de módulos disponibles (según rol)
   - Widget de estadísticas rápidas
   - Actividad reciente
5. Usuario hace click en módulo -> Navega a ruta específica

5.2 NAVEGACIÓN ENTRE MÓDULOS
-----------------------------
Opción A - Con breadcrumbs:
[Dashboard] > [Clientes] > [Nuevo Cliente]

Opción B - Con botón "Volver al Dashboard":
Siempre visible en navbar

Opción C - Menú lateral (estilo Odoo):
Módulos en sidebar, contenido en área principal

DECISIÓN: Opción B + Breadcrumbs (más simple para empezar)
