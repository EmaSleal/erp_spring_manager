## 📚 Recursos Bootstrap Utilizados

### **Utility Classes:**
- `d-none` - Display none (ocultar)
- `d-md-table-cell` - Display table-cell en medium+
- `d-lg-table-cell` - Display table-cell en large+

### **Responsive Breakpoints:**
- `sm`: 576px
- `md`: 768px
- `lg`: 992px
- `xl`: 1200px
- `xxl`: 1400px
