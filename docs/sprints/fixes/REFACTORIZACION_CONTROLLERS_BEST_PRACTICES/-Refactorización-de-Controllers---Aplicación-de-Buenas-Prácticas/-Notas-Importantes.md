## 📝 Notas Importantes

- Si hay código que llama directamente a estos métodos, debe actualizarse

### ✅ Compatibilidad:
- Las vistas (Thymeleaf) no requieren cambios
- Los endpoints HTTP son los mismos
- El comportamiento funcional es idéntico
