## ❌ PROBLEMAS COMUNES

### Error: "XML no válido"
- **Causa:** Falta archivo XSD
- **Solución:** Descargar XSD (ver Sección 1)

### Error: "Certificado no encontrado"
- **Causa:** Ruta incorrecta o archivo no existe
- **Solución:** Verificar HACIENDA_CERTIFICADO_PATH

### Error: "401 Unauthorized"
- **Causa:** Credenciales API incorrectas
- **Solución:** Verificar usuario/password en portal ATV

### Error: "Certificado vencido"
- **Causa:** Certificado .p12 expirado
- **Solución:** Renovar certificado con autoridad certificadora

### Error: "Clave numérica duplicada"
- **Causa:** Consecutivo ya usado
- **Solución:** Sistema incrementa automáticamente, verificar tabla consecutivo_hacienda
