## 🎨 Personalización

### Cambiar breakpoint responsive

Por defecto: 768px. Para modificar, editar en `responsive-table.css`:

```css
@media (max-width: 767px) {  /* Cambiar valor aquí */
    /* Reglas móvil */
}
```

### Colores de estados

```css
.mobile-card-status.status-active {
    background-color: rgba(40, 167, 69, 0.1);
    color: #28a745;
}
```
